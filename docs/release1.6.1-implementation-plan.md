# Stellaris Guide v1.6.1 implementation plan

**Scope:** the Tech Tree and Fleet redesigns supplied by the player on October 19, 2026. The attached HTML pages are visual references and sample data, not game-rule authorities. This patch release keeps the v1.5 process untouched and supersedes the v1.7 labels in those drafts.

## Gates

1. **Research route:** Preserve the selected-save boundary. Read localized names and direct prerequisite links from the matching installed 4.5.x game; render a clickable, illustrated two-lane route with research state, tier gates, and one next action. Do not claim a technology is drawable from prerequisites alone. Verify the Planetary Power Grid branches, missing rules, mod warning, and malformed target cases.
2. **Fleet page:** Replace Ship Builds with Fleet. Show truthful naval-capacity and fleet observations, saved design comparisons, a build planner, and policy summary. Use installed artwork where located. Never invent ship stats, enemy intel, or an optimal loadout from incomplete evidence. Verify arithmetic and failure states against the exact dated fixture and in-game observations.
3. **Release:** Update version and player-facing documentation. Run Python and JavaScript checks, independent code review, and separate security review for new local APIs or asset serving. Build and inspect an isolated Windows package; confirm it opens in Edge and closes, with v1.5 still running.

Before starting each gate, check Codex usage. Follow the v1.6 plan's stop thresholds: at least 15% of the five-hour allowance and more than 5% of the weekly allowance must remain. Do not consume reset credits automatically. Record evidence and unresolved limits below.
