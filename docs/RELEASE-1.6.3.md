# Stellaris Guide 1.6.3

This update adds the first **Strategy playbooks** to next moves for resource deficits and unstable colonies. Expand a playbook beneath a matching goal to see its rule status, strategy status, trade-off, sources and when to change course. The existing goals, priority order and progress display stay intact.

These two playbooks are marked **conditional** and **untested**. They use the save facts already available to the Guide, while their thresholds and proposed actions still require in-game judgment. A later save version or different installed checksum marks the playbook **needs recheck** automatically. Missing facts show **check missing facts**. The Guide does not assume a policy is available merely because it exists in game files.

Expansion and Discovery strategies, fleet matchups, community submissions and playbook advice in AI chat are not included yet. They need additional save data or stronger evidence validation. See [strategy-playbooks.md](strategy-playbooks.md) for their review gates.

## Install

Extract `StellarisGuide-Windows-1.6.3.zip` and double-click `StellarisGuide.exe`. The title badge should say **v1.6.3**. The Guide can run beside an earlier release during testing; use the tray icon to quit the older release when ready.
